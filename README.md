# simple_mind

This repository is a template agent defined using the `Minds` framework.

The full behavior of the agent is defined by the text in the `*.md` files in this repository.

See [the `Minds` documentation](https://github.com/imbue-ai/mng/tree/main/apps/minds/docs/mind/getting_started.md) for more details on how the `Minds` application and how to customize your `Mind`.
