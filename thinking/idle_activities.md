# Idle Activities

Things to consider doing proactively when idle (referenced by the `handle-mind-idle` skill).

- **Fetch latest code**: Pull the latest changes in the target repo checkout so you're always working with current code. See [github_workflow.md](./github_workflow.md) for the command.
- **Check for stale issues**: Use the `update-stale-issues` skill to scan for issues that may need attention (only issues you created).
- **Check for new external issues**: Look for issues created by others that may need labeling or have unanswered questions. Use the `handle-github-events` skill for routing.
- **Ask the user a question**: If there's something you've been uncertain about, this is a good time to ask. Check your memory for any outstanding questions or gaps in your understanding. Be sure not to have too many outstanding questions at once -- you don't want to overwhelm the user. If it's important and it's been a while, you can ask again (or better yet, ask a variant).
- **Onboarding**: If there are uncompleted onboarding items (see [onboarding.md](./onboarding.md)), pick one up.
